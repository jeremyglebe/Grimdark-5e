3:T71f,<p>"Equipment" contains rules on brewing <em>Potions of Healing</em> and scribing <em>Spell Scrolls</em>. To create other magic items, follow the rules below. In these rules, "you" refers to the character crafting the magic item.</p>
<h3>Arcana Proficiency</h3>
<p>To craft a magic item, you and any assistants must have proficiency in the Arcana skill.</p>
<h3>Tools</h3>
<p>The Magic Item Tools table lists which tool is required to make a magic item of each category. You must use the required tool to make an item and have proficiency with that tool. Any assistants must also have proficiency with it. For more information on the tools, see "Equipment."</p>
